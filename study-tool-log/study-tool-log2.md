# 학습 도구 로그 - 2차

- 학습에 도움이 되는 도구를 만들고, 기록합니다. 필요하면 코드를 남깁니다.

## **도구 이름**

막힌 문제 템플릿

## **도구 유형** (예: GPTs, gems, Claude Code(skill, command, agent, ...) Chrome Extension, CLI, 웹사이트 등)

오답노트

## **해결하려는 문제**: 어떤 학습 상의 불편/문제를 해결하려 했는가?'

문제 해결이 안 되었던 이유가 무엇인지 제대로 파악해야지 내가 부족한 부분을 정확히 보충할 수 있을 것이라고 생각했습니다.

`스스로 생각했을 땐 모르는 문법이 존재해서 못푸는 줄 알았는데, 기존에 학습했던 내용으로 충분히 해결할 수 있었던 문제였다.`
같은 내용들을 기록하면서 정말로 부족한 부분을 채우기 위함

## **어떻게 만들었는가**: 간단한 제작 과정

Notion으로 작성해야될 것 같은 내용들을 템플릿화 시켰습니다.

```markdown
# 문제 번호

## 막혔던 부분

## 해결을 위해 필요한 키워드 1개

## 키워드 단순 학습

## 문제에 적용시켜 해결한 방법

## 키워드 심화학습 (생각해볼만한 질문)

## 2회 이상 풀어보며 새로 깨달은 것
```

## **어떻게 활용했는가**

1. 먼저 문제를 풀기 위해선 어떤 방식을 고려해볼지 적어봅니다.
2. 알고있던 내용들을 조합해 해당 방식대로 풀 수 있는지 10분정도 문제를 충분히 고민합니다.

3. 실마리를 전혀 찾지 못했다면, 제작했던 Gems에게 필요한 키워드 딱 1가지만 요청합니다.
4. 강의, 공식문서 등으로 해당 키워드에 대해 학습한 후 문제를 해결해 봅니다.
5. Gems에게 나의 문제 해결과정을 설명하고, 추가로 어떤 부분을 생각하면 좋은지 피드백 받습니다.

## **어떻게 도움이 되었는가**: 실제 사용 경험과 효과

내가 문법을 몰라서 문제를 해결하지 못했는지 아니면 충분히 해결할 수 있었음에도 문제해결을 못했던 것인지 구분할 수 있었습니다.

심화학습을 진행하면서 해당 키워드를 더 잘 이해하기 위한 부수적인 키워드에 대한 학습도 할 수 있었습니다.
